{{/* iframe shortcode：在文章中嵌入 HTML 页面。 参数： src (必填) iframe 地址。同站路径（如 /loadgen/xxx.html，文件放 static/ 下）支持自动量高； 跨域 URL 无法读取内容高度，将保持 height 固定值（且对方站点可能拒绝被嵌）。 title (可选) 无障碍标题，默认 "iframe"。 height (可选) 初始/回退高度，默认 700px；fixed 模式下即最终高度。 fixed (可选) "true" 时关闭自动量高。适用于 100vh 布局的页面（如 Grafana 面板）—— 这类页面高度跟随 iframe 视口，自动量高会把它压成一条缝。 自动量高原理（fixed 未开启时）： - 量高时先把 iframe 收缩到 10px，再读文档 scrollHeight，排除视口高度对文档高度的干扰 （scrollHeight = max(内容高度, 视口高度)，不收缩量到的只是视口高度）； - load、窗口 resize（宽度变化时内容可能响应式重排）、内容尺寸变化（ResizeObserver， 覆盖异步渲染后长高的情况）时重新量高； - 跨域时访问 contentDocument 抛异常，catch 中回退到 height 固定值。 */}} {{- $src := .Get "src" -}} {{- $height := .Get "height" | default "700px" -}} {{- $title := .Get "title" | default "iframe" -}} {{- $fixed := .Get "fixed" | default "false" -}} {{- $id := printf "hugo-iframe-%d" .Ordinal -}} {{ if ne $fixed "true" }} {{ end }}
